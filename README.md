# Simple Signal

A simple Android app that shows your signal, your SIMs, and your Wi-Fi in plain words.

- Home: signal number, speed check, switch SIM, Wi-Fi panel
- SIMs: each SIM, its signal, and which one is used for data
- Wi-Fi: connection name, signal, and link speed

Android does not let apps switch the data SIM or turn Wi-Fi on and off by themselves,
so those buttons open the phone's settings where you make the change.
